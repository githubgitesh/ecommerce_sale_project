# Ecommerce Sale Project - Mahajan Store

## 📊 Project Overview
This is an e-commerce sales analytics project for **Mahajan Store**, containing comprehensive sales data, customer information, and interactive Power BI dashboards for business intelligence and performance analysis.

## 📁 Project Structure

### Files Included:
1. **Mahajan Store.pbix** - Power BI Dashboard
   - Interactive visualizations for sales performance
   - Customer analytics and trends
   - Product category analysis

2. **Orders.csv** - Customer Orders Data
   - Order ID, Order Date
   - Customer Name, State, City
   - Geographic distribution across Indian states

3. **Details.csv** - Transaction Details
   - Order ID, Amount, Profit, Quantity
   - Product Categories (Electronics, Furniture, Clothing)
   - Sub-categories breakdown
   - Payment modes (COD, EMI, Credit Card, Debit Card, UPI)

## 📈 Key Metrics
- **Total Orders**: 1000+ transactions
- **Product Categories**: 3 (Electronics, Furniture, Clothing)
- **Coverage**: Multiple Indian states
- **Payment Methods**: 5 different payment modes

## 🎯 Features
- Sales performance tracking
- Profit margin analysis
- Customer geographic distribution
- Product category insights
- Payment method preferences

## 🛠️ Technologies Used
- **Power BI** - Data visualization and dashboard creation
- **CSV** - Data storage and management

## 📊 How to Use
1. Open **Mahajan Store.pbix** in Power BI Desktop
2. Explore various dashboard visualizations
3. Analyze sales trends using Orders and Details data
4. Generate insights for business decision-making

## 💡 Insights Available
- Best-performing product categories
- Profit vs. revenue analysis
- Regional sales distribution
- Customer purchasing patterns
- Payment preference trends
